# codex-test

一个无需构建工具、无需安装依赖的最小 HTML + SVG 示例：鹈鹕骑自行车。

## 打开方式

1. 下载此仓库（GitHub 页面点击 **Code → Download ZIP**，然后解压），或克隆仓库。
2. 在 Chrome、Edge、Firefox 或 Safari 的现代版本中直接打开 `index.html`（双击文件，或将文件拖入浏览器）。
3. 页面会自动播放动画，点击“暂停动画 / 播放动画”可切换状态。

无需启动服务器。全部样式、SVG 和 JavaScript 都在 HTML 内，没有外部图片、字体、脚本或网络请求，可离线打开。GitHub 的文件页面只展示源码，运行时请打开下载后的 HTML 文件。

## 文件说明

- `index.html`：页面结构、内联 CSS、SVG 插画，以及由 `requestAnimationFrame` 驱动的动画。
- `README.md`：运行方式、实现范围和基础验证步骤。

## 已实现的效果

- 鹈鹕和自行车的基础 2D SVG 插画。
- 两个车轮的辐条旋转，曲柄转动，双腿交替踩踏。
- 身体轻微起伏，路面标线向后移动，形成原地骑行的视觉效果。
- 暂停与继续播放；画面随页面宽度等比例缩放。
- 遵循系统“减少动态效果”偏好：开启时默认暂停，可手动播放。
- SVG 提供文字描述；禁用 JavaScript 时保留静态插画并显示提示。

这是简化的循环动画，没有真实物理模拟、方向控制或游戏玩法。

## 基础验证步骤

1. **直接打开**：以本地 `file://` 方式打开 `index.html`，确认中文标题、鹈鹕和自行车正常显示。
2. **观察动画**：观察几秒，确认两轮辐条转动、双脚交替运动、路面标线连续向左滚动。
3. **暂停与继续**：点击“暂停动画”，确认所有运动停止；点击“播放动画”，确认从当前姿态继续。也可用 Tab 聚焦按钮，再按 Enter 或空格操作。
4. **调整窗口**：缩小到手机宽度，确认插画完整显示，页面无横向滚动条。
5. **离线检查**：断开网络后刷新本地文件，页面仍可播放。打开开发者工具，确认控制台无错误，页面没有请求外部资源。
6. **减少动态效果**：在系统或浏览器开发者工具中启用 `prefers-reduced-motion: reduce` 后刷新，确认初始为暂停状态，按钮可手动播放。
7. **禁用脚本**：禁用 JavaScript 后刷新，确认静态 SVG 插画和启用脚本的提示仍显示。

以上是可手动重复的验证步骤，不依赖测试框架。
